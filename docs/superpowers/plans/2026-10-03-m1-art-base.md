# M1 Art Base Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Replace all gray box visuals with generated Cel Shift pixel art: 18 technician clips, tiles, hazards, props, and UI.

**Architecture:** `tools/animation_assets.py` renders technician clips. `tools/sprite_assets.py` renders catalog assets from `art/cel-shift/catalog.json` into per group frames and manifests. `tools/sprite_assets.py palette --group <group>` applies one shared palette per group, including `animations`. Godot loads textures through `game/sprite_library.gd`, which reads the group manifests.

**Spec:** `docs/superpowers/specs/2026-10-03-datacenter-side-scroller-design.md`. **Master plan:** M1 section of `docs/superpowers/plans/2026-10-03-datacenter-side-scroller.md`.

## Tasks

- [ ] **Task 1: Clip tables.** Add `jump` and `slide` to `CLIPS`, `FPS`, `NORMAL_COUNTS`, and `NORMAL_POSES` in `tools/animation_assets.py`, and to `CLIPS` and `FRAME_COUNTS` in `game/animation_library.gd`. Test: `test_clip_tables_cover_platformer_moves`.
- [ ] **Task 2: Sprite tool.** `tools/sprite_assets.py` with `source_size`, `render`, `normalize` (box downsample, alpha threshold 128), `apply_group_palette`, `group_colors`, and `write_manifest`. Tests: `tests/test_sprite_assets.py`. The shipped asset test stays red until Task 4.
- [ ] **Task 3: Technician clips.** Render and normalize 16 clips. Inspect each preview. Render again with a corrected prompt on a failure, up to 3 times per clip. Then run `sprite_assets.py palette --group animations` and `animation_assets.py manifest`. Expect `Manifest clips: 18`.
- [ ] **Task 4: Catalog art.** Render and normalize 21 catalog assets. Inspect each frame sheet. Run `palette` and `manifest` for `tiles`, `hazards`, `props`, and `ui`. The shipped asset test turns green.
- [ ] **Task 5: Sprite library.** `game/sprite_library.gd`: `func load_group(group: String) -> bool`, `func texture(group: String, name: String, frame: int = 0) -> Texture2D`, `func frames(group: String, name: String) -> SpriteFrames`, `var error_message`. Test `tests/sprite_library_test.gd` with the shipped manifests: every catalog asset loads at its cell size; an unknown name returns `null` with an error message.
- [ ] **Task 6: Player animation.** `Player.choose_clip(on_floor, velocity, sliding, hurt, action) -> StringName` (pure, static). Replace the `Body` rect with an `AnimatedSprite2D` named `Sprite` at (0, -80). `player.configure(library)` sets the frames for `character + "-midcreek"`. Flip on `motor.facing`. Tests in `tests/player_test.gd` for each branch of `choose_clip`.
- [ ] **Task 7: Level visuals.** `level_builder.gd` uses tile textures: solids draw repeated `floor`, `platform`, or `tray` textures with `TextureRect` (tile mode) instead of `ColorRect`. Entities draw their textures (`rack-ok` or `rack-fault`, `exit-open` or `exit-closed`, `checkpoint-off` or animated `checkpoint-on`, `coolant`, `cable-snag`). `level.gd` loads the sprite library and the animation library and reports missing art on screen. The environment background `cold-aisle` uses the existing `layers/` set with parallax. Tests: `tests/level_builder_test.gd` and `tests/level_test.gd` check that sprites have textures.
- [ ] **Task 8: HUD art.** Health segments use `health-full` and `health-empty`. Task rows use `task-open` and `task-done`. Results show `star-on` and `star-off`. Update `tests/hud_test.gd`.
- [ ] **Task 9: Export, CI, README.** Add the 4 group manifests to `include_filter`. Exclude `art/cel-shift/*/generated/*` and `art/cel-shift/*/prompts/*`. Extend `export_test.gd` with 1 texture per group. Remove the `world_test.gd` skips in CI and in the local full suite. Update the README.
